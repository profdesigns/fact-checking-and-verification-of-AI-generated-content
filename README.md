# Fact-Checking and Verification of AI-Generated Content

Verifying claims made by AI models against primary sources, with a focus on maritime affairs, environmental sustainability, and Nigerian policy topics.

## Purpose
Each case below documents a prompt given to an AI model, its response, and a line-by-line verification of the claims made against the sources it cited (or should have cited).
