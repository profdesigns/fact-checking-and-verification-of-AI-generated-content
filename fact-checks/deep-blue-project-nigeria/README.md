# Fact-Check: Deep Blue Project (Nigeria Maritime Security)

## Prompt Given to AI
"What is the current status of Nigeria's Deep Blue Project in combating piracy in the Gulf of Guinea, including vessel and personnel numbers as of this year?"

## AI Response Summary
The AI described the Deep Blue Project as active, led by NIMASA with the Navy, Air Force, and Army, crediting it with a significant drop in piracy. It provided a fleet inventory (2 Special Mission Vessels, 17 Fast Interceptor Boats, 2 Special Mission Aircraft, 2-3 helicopters, 8 UAVs, 26 armored vehicles) and personnel figures (600 original troops, 492 + 177 graduated personnel, with a detailed role breakdown).

## Sources Cited by the AI
1. ShippingWorld-NG — "Nigeria Receives Last Batch of Assets Under Deep Blue Project"
2. Shipsandports.com.ng — "NIMASA Graduates 492 Advanced Combat Personnel"
3. DailyTrend — "NIMASA Inducts 177 Fresh Security Personnel"

## Verification Findings

| Claim | AI Stated | Source Says | Verdict |
|---|---|---|---|
| Special Mission Vessels | 2 | 2 | ✅ Correct |
| Fast Interceptor Boats | 17 | 17 | ✅ Correct |
| UAVs/Drones | 8 | 4 | ❌ Incorrect |
| Armored Tactical Vehicles | 26 | 16 | ❌ Incorrect |
| Personnel graduated (492 + 177) | Matches | Matches | ✅ Correct |
| 177-person role breakdown | Matches DailyTrend | Matches | ✅ Correct |
| "232 MSU combat operatives," "100+ FIB crew," etc. | Stated as fact | Not found in any cited source | ❌ Unsupported/fabricated |
| Bakassi Peninsula/Igbokoda footprint expansion | Stated as fact | Not found in any cited source | ❌ Unverified |

## Key Issue: Temporal Conflation
The response blends two different reporting periods and NIMASA leaderships without flagging the shift — an earlier account (under DG Bashir Jamoh, discussing a Jan–March piracy window) and a more recent one (under DG Dayo Mobereola in 2026, citing "four consecutive years without piracy"). Presenting both as one continuous, current picture risks misrepresenting how current each data point actually is.

## Conclusion
The AI got the core vessel/asset numbers largely right but introduced two clear numerical errors (UAVs, armored vehicles) and fabricated a detailed personnel role breakdown with no supporting citation. This illustrates how confidently an LLM can state invented statistics alongside verified ones.
